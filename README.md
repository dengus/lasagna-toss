# Lasagna Toss!

A silly kids browser game — make a lasagna, bake it, then toss slices to hungry cartoon targets!

## Play online

Open the GitHub Pages URL once enabled (or open `index.html` locally).

## Mobile tips

- Add to Home Screen on iPhone/iPad for a full-screen feel.
- Portrait and landscape both work; use big finger taps on the ingredient buttons and drag on the canvas to aim.
